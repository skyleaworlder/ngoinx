# WebSearch

## Tool Description
Performs web searches for real-time or current external information not guaranteed by local/project context.  
Returns search snippets and URLs.

Typical use cases:
- Current events
- Latest package/version information
- Recent external documentation updates

## Tool Param
### search_term
* description: Query string to search on the web (should be specific; include versions/dates when relevant).
* type: string
* required: yes

### explanation
* description: One-sentence reason for using web search and how it helps the task.
* type: string
* required: no
